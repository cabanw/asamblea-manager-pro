# Project Technologies

This document outlines the key technologies and libraries used in this project.

## Core Technologies

*   **React:** A JavaScript library for building user interfaces.
*   **Vite:** A fast build tool and development server for modern web projects.
*   **React Router:** For handling routing in the React application.
*   **TypeScript:** A typed superset of JavaScript that compiles to plain JavaScript.

## UI & Styling

*   **shadcn/ui:** A collection of reusable UI components.
*   **Tailwind CSS:** A utility-first CSS framework for rapid UI development.
*   **Radix UI:** A library of unstyled, accessible UI components.
*   **Lucide React:** A library of simply designed, beautiful icons.

## State Management & Data Fetching

*   **TanStack Query:** A powerful data-fetching and state-management library for React.
*   **Supabase:** An open-source Firebase alternative for building secure and scalable applications.

## Forms

*   **React Hook Form:** A library for managing forms in React.
*   **Zod:** A TypeScript-first schema declaration and validation library.

## Development Tools & Utilities

*   **ESLint:** A pluggable and configurable linter tool for identifying and reporting on patterns in JavaScript.
*   **Vitest:** A blazing fast unit-test framework powered by Vite.
*   **PostCSS:** A tool for transforming CSS with JavaScript plugins.
*   **Autoprefixer:** A PostCSS plugin to parse CSS and add vendor prefixes to CSS rules.
